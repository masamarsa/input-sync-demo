# PHP Input Sync 試作

PHP の組み込み開発サーバーと JSON ファイルを使い、フォーム入力を別タブへ同期する小さな動作確認用アプリです。

## 起動

```sh
cd /Users/marsa/Sites/public/input-sync-demo
php -S 127.0.0.1:8000
```

ブラウザーで <http://127.0.0.1:8000> を開き、同じ URL を別タブでも開いてください。テキスト入力、自由記入欄、ラジオボタン、チェックボックスの状態が同期されます。

## 仕様

- 自由記入欄は最大100,000文字（UTF-8で最大512 KiB）です。大きめの入力は500 msのデバウンス後に同期します。
- 表示形式は RAW データ、Markdown パース済み、プレーンテキストから選べます。RAW は入力をそのまま表示し、Markdown は見出し・強調・リスト・引用・コード・HTTP(S)リンクを描画します。プレーンテキストはMarkdown記法を除いて表示します。表示形式の選択はブラウザータブごとに適用されます。

- ブラウザーは 700 ms ごとにサーバーの状態を確認し、入力変更は短いデバウンス後に保存します。
- PHP は更新内容を `sys_get_temp_dir()` 配下の JSON ファイルに保存します。フォームの値を Web 公開ディレクトリーには置きません。
- 更新番号（revision）で新しい状態を判定します。複数画面から同じ項目を同時に変更した場合は、サーバーに後から届いた値が反映されます。
- 「全端末の状態をリセット」は共有 JSON の値を空にします。
- この試作には認証がありません。ローカルでの確認に使い、個人情報や機密情報は入力しないでください。
